# Life Mini IA

**Life Mini IA** est un petit espace personnel en français pour organiser sa journée sans se mettre la pression. L’application fonctionne directement dans le navigateur et conserve les tâches, l’humeur et les notes sur l’appareil.

## Utiliser l’application

Ouvrir `index.html` dans un navigateur moderne. Aucune installation n’est nécessaire.

## Fonctions

- Tableau de bord quotidien avec tâches et progression
- Ajout, suppression et validation de tâches
- Suivi de l’humeur
- Carnet de notes sauvegardé localement
- Assistant de soutien avec réponses prédéfinies, sans envoi de données
- Exercice de respiration guidée
- Mise en page adaptée aux mobiles

## Vie privée

Les informations restent dans le stockage local du navigateur. L’assistant est une démonstration locale et ne contacte aucun service d’IA.

## Publication

Le site est statique et peut être publié avec GitHub Pages depuis la branche principale, à la racine du dépôt.
